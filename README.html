1 · About this repository

United States University (USU) is a wholly-owned subsidiary of Aspen Group, Inc. (AGI), which provides shared services under a Service Level Agreement. The SLA was redrafted in 2026 after a board-level review (the “MOS” comments, September 12, 2026), producing Draft 2.0. That draft was then examined by four AI systems working independently, compared by three syntheses, and reconciled by a fusion panel into a final board brief.

This repository preserves the complete documentary record of that process so that trustees, executives, counsel, and auditors can trace any conclusion back to its source. Start at the document hub (index.html) — it links exactly one canonical version of every document and maps all duplicate formats in its inventory.

Headline finding The four independent reviews agree the draft is a sound governance framework that is not yet an executable operating agreement. Consensus recommendation: endorse in principle; do not authorize signature until the pre-signature worklist (metrics exhibit, employer register, system inventory, delegation schedule, commercial terms) is complete.

2 · The review process

▸

▸

▸
Nov 20, 20263 syntheses of all four reviews (GPT, Gemini Pro, Claude Haiku)
▸
Nov 20, 2026Fusion panel reconciles the syntheses → final Board brief

Each stage deliberately used different models so that later stages could check and correct earlier ones rather than inherit a single system’s blind spots. The fusion panel caught real errors — most notably, one synthesis labeled several disputed implementation details “unanimous”; the panel traced them back to direct conflicts and replaced the unanimity claims with attributed support.

The traceability from the MOS comments through Draft 2.0 to the AI findings is documented item-by-item in the traceability report; the board-level orientation is the master view; and the six-stage flow in one page — what consumed what — is the review roadmap.

5 · File and format conventions

  • Canonical formats. Where a document exists in multiple formats, hubs and readmes link exactly one version, preferring HTML → PDF → MD. Alternates are recorded in the hub inventory.
  • Stage-1 workspaces are interactive. The four AI reviews are self-contained HTML applications with filters, per-item status tracking, and note export. Notes are stored in the reviewer’s browser (by design — no data leaves the page).
  • Naming. Source documents keep their original filenames (including spaces and en-dashes); generated documents use hyphenated names. Links are percent-encoded and case-sensitive.
  • Drafts are labeled. The traceability report is marked DRAFT 1 pending markup of its per-item dispositions.

6 · Hosting on GitHub Pages

  1. Push this directory’s contents to the repository root (or a folder such as docs/).
  2. In repository Settings → Pages, deploy from the branch and folder containing index.html.
  3. All links are relative, so the site works at the root path or any subpath with no configuration.
Hosting notes GitHub Pages is case-sensitive — keep filenames exactly as committed (note the uppercase extensions .HTML / .PDF / .MD on several source files). No build step is required; there are no external assets or dependencies. A .nojekyll file is harmless but unnecessary here.

7 · Provenance, caveats, and status

What is AI-generated

The four Stage-1 reviews, the three syntheses, the fusion transcript, and the final brief were produced by AI systems (ChatGPT, Claude, Copilot, Perplexity, GPT, Gemini Pro, Claude Haiku). The MOS board summary is itself an AI-prepared condensation of the reviewer’s 19 comments. The master view, traceability report, hub, and this readme are AI-prepared navigation aids.

Standing caveats
  • Nothing was independently verified. No stage checked the SLA against the 2017 acquisition/intercompany agreements or external regulation (WSCUC, U.S. ED, FERPA, state boards).
  • AI output is not legal advice. External-compliance assertions in the reviews must be verified with counsel before the Board relies on them.
  • Silence ≠ agreement. Review depth varies 10–28 items; a shorter review’s omissions reflect scope, not position.
  • Priority labels mix rubrics. “Critical/High” indicates reviewer emphasis, not a common severity standard.

Open items

  • Comment MOS17 is not itemized in the board summary; its disposition is unconfirmed (see traceability report §3.6).
  • The traceability report is Draft 1 — dispositions await working-group markup.
  • The Board still owes decisions on the four open governance choices: incident-notice trigger, signature-vs-effectiveness gating, materiality definition, and approval mechanics.
